# ESPImageDisplay 1.1.13

Stable firmware for the Waveshare ESP32-S3 Touch AMOLED 1.43 (466 x 466).
This release contains only the `ESP32_S3_AMOLED_143` board package.

[Download AMOLED firmware](https://github.com/thelastoutpostworkshop/ESPImageFirmware/releases/download/v1.1.13/ESPImageDisplay-ESP32_S3_AMOLED_143-1.1.13.zip)

## Features

- Round AMOLED display with SH8601/CO5300 controller support.
- FT3168 touch and SD-card image/video playback.
- USB identification and Wi-Fi setup through ESPImageServer.

Use an ESPImageServer version that includes the AMOLED board option in
**Set up display**. Choose the exact board model before installing.
Wi-Fi credentials are configured through the app; no SD contents are included.
