## Changes

- Network registration reports the explicit compiled `board_target`.
- USB identification and network registration share the same board identifier.
- Updated ESPImageServer builds use this identifier for firmware update notifications instead of guessing from screen dimensions or display names.

## App compatibility

Update the app and firmware together. Use an ESPImageServer build that accepts `board_target` in `/displays/register`. Earlier server builds may reject this field; updated server builds require it. USB identification still verifies the physical board before installation.
