# ESPImageDisplay 1.1.4

Hardware results below were confirmed on 2026-09-12. Full recovery testing
remains open; see the board-specific results below.

## Included boards

- JC4827W543, 480 × 272.
- ESP32-C6 LCD 1.47, 172 × 320.
- Waveshare ESP32-S3 3.16-inch / ST7701, 320 × 820.

## Features

- USB firmware identification and Wi-Fi provisioning through ESPImageServer.
- Forget Wi-Fi through the desktop app while preserving SD files and other
  display settings.
- LAN image delivery and SD-card operations through ESPImageServer.

## Hardware results and remaining checks

- JC4827W543: desktop flashing/boot, USB identification, Wi-Fi setup,
  power-cycle persistence, and Forget Wi-Fi/reprovisioning were user-confirmed.
- C6: desktop flashing and network connection were user-confirmed.
- ST7701: desktop flashing and network connection were user-confirmed. SD-card
  insertion and an image save completed, but the save took longer than expected.
- Busy/disconnected USB ports, interrupted writes, Wi-Fi failure/rollback,
  multiple-device selection, and server-outage recovery still need full
  board-specific acceptance testing.
- Some status text can be clipped, and the native ST7701 status font omits
  digits/punctuation. The 1.1.5 source adds adaptive layout and font corrections.

These are first-install packages. Settings preservation is not guaranteed when
the old partition layout differs. Use the matching board ZIP, extract it into
the desktop app's firmware library, and review its installation notice.

## Install

In the updated ESPImageServer desktop app, open **Set up display** and check
the USB display. The app finds matching releases and downloads the firmware
for you. Review and confirm installation before it writes to the board.
Older app versions can download and extract the matching ZIP manually.
