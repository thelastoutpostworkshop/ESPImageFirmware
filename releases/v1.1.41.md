# ESPImageDisplay 1.1.41

Firmware packages for all five supported displays. Select the package matching your physical board in ESPImageServer’s **Set up display** page.

## Release readiness

Draft release containing validated firmware packages for all five supported boards and SHA256SUMS.txt. Package checks and desktop validation passed. Credential-free build confirmation and physical-board acceptance have not been recorded; keep the release unpublished until readiness evidence is recorded.

## Included boards

- JC4827W543 (480 x 272)
- Waveshare ST7701 (320 x 820)
- ESP32-C6 LCD 1.47 (172 x 320)
- Cheap Yellow Display (240 x 320)
- Waveshare ESP32-S3 Touch AMOLED 1.43 (466 x 466)

## Changes since 1.1.39

- Bulk SD-card saves show the current item and total count.
- Each bulk item waits for its optional thumbnail transfer before acknowledging completion.
- Thumbnail failures preserve successfully saved media.
- Cancellation after a committed save acknowledges that completed item before stopping the remaining batch.
- Duplicate acknowledged commands are handled safely.
- Image and video save status messages are clearer.

## App compatibility

Use an ESPImageServer build with gallery bulk-save support for batch progress and cancellation. Board identity in USB and network registration remains unchanged. Firmware packages continue to use exact board-specific filenames for app discovery.

## Validation and provenance

- All five supplied exports identify version 1.1.41 and the matching compiled target in their copied FirmwareTarget.h. Application binaries contain the expected version and board identifier; this alone does not establish credential safety or physical acceptance.
- Firmware checkout observed during preparation: `297a4f43ae9299d81ae66a226ad43ee20722a388`, clean. Build metadata does not independently record the source commit used at compilation.
- Exact profiles, FQBNs, toolchain/library package identities, copied-header hashes and segment hashes: [build provenance](https://github.com/thelastoutpostworkshop/ESPImageFirmware/blob/v1.1.41/releases/v1.1.41-builds.json).
- All five local manifests and release ZIPs passed metadata, chip-header, offset, erase-overlap, flash-capacity, partition-fit and hash validation. All five extracted packages passed the desktop firmware validator.
- Firmware distribution tooling: 13 tests passed using mocked GitHub interactions; this did not create or publish a release.
- Supplied dependency files do not reference secrets.h. This does not prove that binaries are credential-free.
- No firmware compilation, linking, flashing or physical-board tests were performed by the agent.
