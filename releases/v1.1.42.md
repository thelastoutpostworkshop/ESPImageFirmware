# ESPImageDisplay 1.1.42

Firmware package for ESP32-C6 LCD 1.47 (172 x 320).

## Release readiness

Ready for the requested publication: the C6 package and extracted ZIP passed release and desktop validation, and current hardware acceptance was confirmed by the maintainer.

The maintainer confirmed on 2026-10-10 that this C6 1.1.42 build passed hardware testing, including SD video playback and continued app communication. This is maintainer-reported acceptance; the agent did not flash or test a physical board.

The supplied manual build uses the current USB/device-storage Wi-Fi configuration path. Copied configuration and provisioning sources match the clean firmware checkout; no secrets.h dependency or translation-unit reference was found. This supports a fresh credential-free release build, with the verification limits recorded below.

## Included boards

- ESP32-C6 LCD 1.47 (172 x 320)

## Changes since 1.1.41

- Fix SD-card video playback on ESP32-C6 LCD 1.47 boards without PSRAM by reducing the MJPEG frame buffer to 32 KiB. This avoids the memory-allocation failure that prevented movies from playing.

## App compatibility

Use ESPImageServer's **Set up display** page to select the matching C6 package. USB and network board identity remain unchanged. This release contains only the C6 package; the other four displays retain their published 1.1.41 packages.
