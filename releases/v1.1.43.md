# ESPImageDisplay 1.1.43

Firmware package for Cheap Yellow Display (240 x 320).

## Release readiness

Ready for the requested publication. On 2026-10-12, the maintainer confirmed
that this CYD 1.1.43 build passed hardware testing, including boot/app connection,
SD media playback and saving, and offline/recovery behavior: "Yes, all passed".
These are maintainer-reported results; the agent did not flash or test hardware.
The earlier IMG_7991.MOV recording also shows the improved penguin whites and
skin tones with the same gamma setup.

Source/export correspondence and dependency checks support a fresh credential-free
build using USB provisioning and device NVS. Verification limits are recorded
below and in the accompanying build record.

## Included boards

- Cheap Yellow Display (240 x 320)

## Changes since 1.1.42

- Improve image and video colors on the Cheap Yellow Display by explicitly
  initializing the LCD gamma tables. This corrects the strong blue/cyan cast
  observed in white areas and skin tones on the tested board.

## App compatibility

ESPImageServer discovers the published CYD package by its exact board identifier
and ZIP filename. USB/network identity and native dimensions remain unchanged.
This release includes only CYD. ESP32-C6 LCD 1.47 remains at 1.1.42; JC4827W543,
Waveshare ST7701, and Waveshare AMOLED retain their 1.1.41 packages.
The previous published CYD package is 1.1.41.

## Remaining limitations and notices

Hardware acceptance covers the maintainer's CYD. It does not establish measured
color accuracy or performance on every LCD panel variant. Native bitmap diagnostic
streaks remain unexplained; normal artwork uses the tested big-endian JPEG path.
The optional diagnostic remains disabled in this release.

The ZIP retains the project license and existing notices. The gamma register
source attribution remains in CheapYellowDisplay.cpp. SHA256SUMS.txt records the
release ZIP hash. Generated binaries and ZIPs remain outside Git history.
