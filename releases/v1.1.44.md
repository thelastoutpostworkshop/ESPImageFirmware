# ESPImageDisplay 1.1.44

Firmware packages for all five supported displays. Select the package matching
your physical board in ESPImageServer's **Set up display** page.

## Included boards

- JC4827W543 (480 x 272)
- Waveshare ST7701 (320 x 820)
- ESP32-C6 LCD 1.47 (172 x 320)
- Cheap Yellow Display (240 x 320)
- Waveshare ESP32-S3 Touch AMOLED 1.43 (466 x 466)

## Changes since 1.1.43

- Choose one saved orientation for SD-card image slideshows or video loops:
  0°, 90°, 180°, or 270°. Filtering is off by default.
- Use the selected orientation during previews and offline playback, including
  newest-first, oldest-first, and random order. The display reports when no
  matching media is available.
- Preserve the prepared image and its rotation during queued SD-card saves.

## Configuration and notices

The Display Experience settings record is now version 3. Previous saved
Display Experience settings must be saved again after installation. Orientation
information is recorded in newly app-saved SD filenames; when filtering is
enabled, files without identifiable orientation are excluded. No pixel rotation
or compatibility migration is performed by the firmware.

This release retains the C6 MJPEG memory fix and CYD gamma correction from their
earlier releases. All ZIPs include the project license, the existing AMOLED
Apache-2.0 attribution, and the TFT_eSPI FreeBSD notice for CYD gamma tables.
Generated binaries and ZIPs remain outside Git history.
