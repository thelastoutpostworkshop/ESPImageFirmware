# ESPImageDisplay 1.1.45

Firmware packages for all five supported displays. Select the package matching
your physical board in ESPImageServer's **Set up display** page.

## Included boards

- JC4827W543 (480 x 272)
- Waveshare ST7701 (320 x 820)
- ESP32-C6 LCD 1.47 (172 x 320)
- Cheap Yellow Display (240 x 320)
- Waveshare ESP32-S3 Touch AMOLED 1.43 (466 x 466)

## Changes since 1.1.44

- Fix video-loop previews and offline playback stalling on native-USB displays
  when the serial monitor is closed.
- Prevent optional diagnostic output from blocking playback or delaying display
  command acknowledgements.
- Keep USB setup responses complete while diagnostic output is busy.

## Release readiness and hardware acceptance

Ready for publication. On 2026-10-14, the maintainer confirmed that all five
rebuilt 1.1.45 boards passed hardware testing, including video-loop preview and
offline playback with the serial monitor closed, USB setup/app connection, and
SD playback and saving: "Yes, all five passed". These are maintainer-reported
results; the agent did not compile, link, flash, or test physical hardware.

## Configuration and notices

This release changes optional native-USB diagnostics without changing media
formats or Display Experience configuration. CYD continues using its UART
diagnostic path. USB identity and Wi-Fi setup replies remain complete framed
responses.

All ZIPs retain the project license, AMOLED Apache-2.0 attribution, and the
TFT_eSPI FreeBSD notice for CYD gamma tables. Generated binaries and ZIPs remain
outside Git history.
