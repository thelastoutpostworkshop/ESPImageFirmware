# ESPImageDisplay 1.1.5

Draft release preparation for Cheap Yellow Display (240 × 320). Compilation and
package validation are complete; physical flashing, boot, and readability of
this build have not yet been confirmed here. Keep it a draft or pre-release
until the intended hardware checks are complete.

## Changes

- Status messages wrap and scale to the screen dimensions.
- Long filenames wrap; oversized details show an ellipsis while keeping space
  for the heading and SD-card status.
- Clearer instructions for Wi-Fi setup using USB and the desktop app.
- Shared source includes Waveshare digit/punctuation support; this release's
  prepared assets currently contain only the Cheap Yellow Display build.

## Validation

- Manual Arduino compilation completed successfully on 2026-09-12.
- Package checks cover sizes, SHA-256 hashes, ESP32 image headers, flash offsets,
  and application partition fit.
- Shared status-layout assertions and pixel previews passed. These do not
  replace checking the physical screen.
- Boot, USB provisioning, saved Wi-Fi, SD operations, and failure/recovery
  acceptance remain to be recorded for this board/version.

This is a first-install package for 4 MB flash. Extract its ZIP into the desktop
firmware library and select Cheap Yellow Display. Settings may be lost if the
previous partition layout differs.
